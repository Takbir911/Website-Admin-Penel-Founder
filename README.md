🚀 Website Admin Panel Finder

A Python-Based Website Route Discovery Tool

A command-line tool for discovering common website routes on authorized targets.

---

✨ FEATURES

- ✅ Common Route Discovery
- ✅ HTTP Status Code Checking
- ✅ Basic Login-Page Indicator Detection
- ✅ JSON & TXT Report Generation
- ✅ Termux (Android) Support
- ✅ Kali Linux Support

---

📱 INSTALLATION GUIDE — TERMUX

STEP 1: Update Packages

pkg update

STEP 2: Install Required Packages

pkg install python git -y

STEP 3: Clone the Repository

git clone https://github.com/Takbir911/Website-Admin-Penel-Founder.git

STEP 4: Enter the Project Directory

cd Website-Admin-Penel-Founder

STEP 5: Install Dependencies

python -m pip install -r requirements.txt

STEP 6: Run the Tool

python admin_penel.py

---

🐉 INSTALLATION GUIDE — KALI LINUX

STEP 1: Update Package Information

sudo apt update

STEP 2: Install Required Packages

sudo apt install -y python3 python3-venv python3-pip git

STEP 3: Clone the Repository

git clone https://github.com/Takbir911/Website-Admin-Penel-Founder.git

STEP 4: Enter the Project Directory

cd Website-Admin-Penel-Founder

STEP 5: Create a Virtual Environment

python3 -m venv .venv

STEP 6: Activate the Virtual Environment

source .venv/bin/activate

STEP 7: Install Dependencies

python -m pip install -r requirements.txt

STEP 8: Run the Tool

python admin_penel.py

---

📂 OUTPUT FILES

The tool is intended to generate the following reports:

- 📄 "admin_discovery_results.json"
- 📄 "admin_discovery_results.txt"

---

⚠️ IMPORTANT NOTES

- Discovered routes do not necessarily represent administrative panels.
- HTTP status codes alone do not confirm vulnerabilities.
- Results should be verified before drawing conclusions.

---

🛡️ RESPONSIBLE USE

- Use the tool only on websites you own or have explicit permission to test.
- Do not attempt unauthorized access.
- Respect the website owner's rules and stop testing if permission is withdrawn.
